# The Organ Registry

The mid-2026 framework is a set of separate parts. The registry calls them **organs**: practices and controls that can each be adopted, traced or removed on their own. This page is the public form of a fixed, audited list of thirty-two parts, traced through the three projects still using Memento with evidence down to individual commits. The auditor made every verdict at first hand; evidence gathered by helper agents was always checked directly before it was accepted.

**How to read the table.** *Origin* is the period and project where the part first appears in the records (project names kept generic by policy). *Spread* records how widely it took hold: **universal** parts appear in all three projects in some form; **host-specific** parts answer one project's circumstances. Both kinds matter: the universal core is where an adopter starts, and the host-specific parts show the framework fitting itself to each project.

The three projects are the **original project** (the repository where Memento began), the **workstream project** (a shared memory system for a team's business workstreams) and the **mapping project** (a tool for mapping an organisation). "Before publication" means 2025, before the first published version. Terms such as working context, institutional memory and knowledge gardening are explained in [Words used here](../framework/README.md#words-used-here).

## What the spread means

Roughly two dozen parts form a **universal core**, present in every project in versions sized to each. The rest are honest adaptations: a validation ledger where experiments with controls are concentrated, two threads of work where the framework and the product share one working copy, proportionate confidentiality fencing where several people handle confidential material. Read the spread column as advice: the universal core first, then the specialised parts when your circumstances create the need. That order is the [graduation ladder](../adoption/GRADUATION_LADDER.md).
